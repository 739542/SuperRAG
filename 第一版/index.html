Quick Start

建议演示路径

  1. 先在“知识库管理”里确认文档分类与项目归属。
  2. 到“培训模式”演示新人如何理解项目背景与术语。
  3. 到“交接模式”演示任务承接、风险和待办整理。
  4. 最后到“设计辅助”生成功能清单与用例草稿。

核心定位

这版不是聊天壳，而是场景化辅助系统

  • 围绕企业私有知识做结构化检索与设计辅助。
  • 突出培训模式、交接模式、设计模式三类业务场景。
  • 结果中保留依据、风险、后续动作，便于答辩说明。

Usage Notes

如何接 Dify

1. 在 Dify 中分别创建通用检索、培训、交接、设计四个应用或工作流应用。
2. 为每个应用复制 Service API Key，填到左侧对应位置。
3. 通用检索建议接 Chat App；培训、交接、设计建议接 Workflow App。
4. 如果暂时没配通，系统会自动退回到 mock，不影响功能演示。
