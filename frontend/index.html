Quick Start

推荐使用路径

  1. 先在“知识库管理”里上传 txt / md / csv / json / html 等资料。
  2. 回到“通用检索”验证知识库是否能命中关键内容。
  3. 再到“培训模式”和“交接模式”检查场景化输出结构。
  4. 最后用“设计辅助”生成功能清单、文本用例和模块建议。

当前定位

页面壳子在前端，知识处理在后端

  • 前端负责场景组织、输入采集、结果展示和记录回看。
  • 后端负责文档导入、切块、索引、检索和问答生成。
  • 向量库不可用时，后端会自动退回词法检索，保证链路仍可用。

Usage Notes

如何运行

1. 先启动 `dify-lite`，确保 `http://127.0.0.1:8088/api/health` 可访问。
2. 在左侧“知识库管理”上传项目资料，后端会自动按项目名归档到集合。
3. 四个场景都直接请求后端场景接口，不再依赖 Dify Service API Key。
4. 如果 Weaviate 暂时不可用，后端会回退为词法检索，链路依然能跑通。

默认地址

http://127.0.0.1:8088/api
