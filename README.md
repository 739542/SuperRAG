# SuperRAG

课程项目仓库，当前保存的是第一版可演示原型与配套设计文档。

## 当前内容

- `第一版/`
  第一版前端原型，包含知识库管理、通用检索、培训模式、交接模式、设计辅助、结果记录和 Dify 配置页面。
- `docs/设计拆解.md`
  当前阶段的页面清单、Workflow 清单和数据表清单。

## 本地运行

```powershell
cd 第一版
.\start.cmd
```

如果双击打开 `第一版/index.html`，也可以直接看到页面。

## 当前协作建议

- 一人负责前端页面与展示体验
- 一人负责 Dify Workflow 配置与接口联调
- 默认不要同时大改 `第一版/app.js`
